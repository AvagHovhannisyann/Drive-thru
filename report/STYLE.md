# Report chapter style guide (for writers producing HTML fragments)

Output: one HTML fragment per chapter (no `<html>`, `<head>`, `<style>`, `<script>`), written to
`report/fragments/<chapter-id>.html`. The page frame supplies CSS. Use only these elements and classes:

- Headings: start with `<section class="ch" id="<chapter-id>"><div class="eyebrow">Phase N · short label</div><h2>Chapter title</h2>`; inside use `<h3>` / `<h4>`. Close with `</section>`.
- Opening paragraph: `<p class="lede">…</p>` — the chapter's answer in 2–3 sentences (lead with the conclusion).
- Body text: `<p>`, `<ul>`, `<ol>`. Keep paragraphs short. Plain, direct sentences; no hype, no filler ("worth noting", "honest caveat", "in conclusion"), no em-dash asides, no "not X but Y" framing.
- Key figures: `<div class="grid4">` (or grid3/grid2) of `<div class="kpi"><div class="v">VALUE</div><div class="l">label · <span class="tag ESTIMATE">ESTIMATE</span></div></div>`. Use only when the numbers are the point.
- Evidence status: every number that matters carries a tag right after it: `<span class="tag VERIFIED">VERIFIED</span>`, `REPORTED`, `ESTIMATE` or `ASSUMPTION` — copied from the research file's status (after its fact-check log). Never upgrade a status.
- Citations: after a claim, cite the evidence file and its source number, e.g. `<sup>[B1 §2 #13]</sup>`; for the original source give a link once per chapter in a final `<h4>Sources</h4><ol>` list with `<a href="URL">title</a>` (copy URLs exactly from the research file).
- Tables: `<div class="tscroll"><table><thead>…</thead><tbody>…</tbody></table></div>`; right-align numbers with `class="num"`.
- Callouts for decisions/risks: `<div class="callout"><strong>Decision.</strong> …</div>`.
- Armenian text: wrap in `<span class="hy" lang="hy">…</span>`.
- Money: AMD first, USD in parentheses at 361.93 AMD/USD (CBA, 9 Oct 2026), e.g. `183 M AMD ($506k)`. Use thin, consistent units: `M AMD`, `k AMD`, `veh/day`, `tx/day`.
- Placeholders for figures generated by the build script: `<!--FIG:figure-id-->` on its own line (only ids listed in the brief).

Integrity rules (non-negotiable): do not invent any number, quote, company fact, regulation or source. If a needed fact is missing from the files, say so plainly and point to the verification step. When the research is uncertain, give the range and the status. Be critical: include disconfirming evidence and risks, not promotion.
